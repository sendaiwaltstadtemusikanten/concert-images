画像だけを表示するWebページ（GitHub Pages用）

ファイル構成：
- index.html       → 1枚目（プログラム）
- program.jpg      → 1枚目の画像
- lyrics.html      → 2枚目（歌詞）
- lyrics.jpg       → 2枚目の画像

GitHubのPublicリポジトリの直下に、この4ファイルをアップロードし、
Settings → Pages → Deploy from a branch → main → /(root) → Save を設定します。

公開URL：
- https://ユーザー名.github.io/リポジトリ名/
- https://ユーザー名.github.io/リポジトリ名/lyrics.html

ページには画像以外の文字・ボタン・枠を表示しません。
画像全体が見えるよう縦横比を維持するため、画面比率によっては上下左右に
ブラウザ背景（白）が少し見える場合があります。画像を切り抜かない設定です。
